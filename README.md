# 콘솔 가계부

Python 표준 라이브러리만 사용해 수입과 지출을 파일에 영구 저장하고 관리하는 콘솔 프로그램입니다. 거래 CRUD, 조건 검색, 월별 요약, 예산 및 카테고리 관리, CSV 가져오기/내보내기를 제공합니다.

## 과제 핵심 요구사항

- `python -m budget_app <command> [options]` 형태의 CLI와 명령별 `--help`
- 거래의 추가·목록·검색·수정·삭제
- 월별 수입, 지출, 잔액, 지출 카테고리 TOP N 및 예산 사용률 출력
- 카테고리 추가·조회·삭제와 사용 중인 카테고리 삭제 방지
- CSV 일괄 가져오기 및 기간별 내보내기
- 거래·카테고리·예산을 서로 다른 파일에 영구 저장
- 제너레이터 기반 거래 스트리밍, 타입 힌트, 계층별 모듈 분리
- 데코레이터를 통한 공통 오류 처리와 실행 로그 분리
- 잘못된 입력에는 스택 트레이스 대신 원인과 해결 힌트를 출력하고 0이 아닌 종료 코드 반환

## 설계 방향

데이터는 `Transaction`, `Category`, `Budget` 데이터 클래스로 표현합니다. 저장소는 JSONL 파일 I/O와 원자적 재작성을, 서비스는 입력 검증과 업무 규칙을, CLI는 명령 해석과 사용자 입출력을 담당합니다. 기본 카테고리는 첫 실행에 자동으로 생성하며, 거래는 물리적인 저장 역순으로 읽어 최신 등록순을 유지합니다.

> 상세 실행법, 명령 예시, 저장 형식과 CSV 스키마는 기능 구현과 함께 이 문서에 계속 보완합니다.
